# 路线图

## 当前公共数据产品

- Codex 插件与私有 MCP 源码位于同一个可审查 monorepo。
- 使用固定私有包跨机器启动，不依赖源码路径。
- 提供 Spot、USD-M Futures、本地历史与风险审查 Skills。
- 提供内存/SQLite 缓存和 DuckDB/Parquet 历史存储。
- 提供跨平台数据根目录、导入路径约束与有界 HTTPS 导入。
- 提供 MCP、包消费者和跨交付物校验。

## 下一阶段

- 自动发现 `data.binance.vision` 目录与校验值。
- 增加历史资金费率、持仓量、交易者比例、主动成交量与基差数据集。
- 一致展示请求权重、来源数据年龄与获取时间。
- 消除远程导入中 DNS 校验与连接之间的窗口，或增加严格域名白名单。
- 增加发布来源证明和制品 attestations。
- 增加可选 WebSocket 市场数据与快照/增量顺序测试。

## 明确独立的未来产品

如需只读账户研究，应使用不同的 MCP 和最小权限密钥存储。交易执行应使用另一个 testnet-first 服务，并具备预览、明确确认、交易过滤器校验、幂等、限额和审计日志。提现能力继续排除在范围外。
