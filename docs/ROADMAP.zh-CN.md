# 路线图

## 当前研究产品

- Codex 插件与私有 MCP 源码位于同一个可审查 monorepo。
- 使用固定私有包跨机器启动，不依赖源码路径。
- 提供 Spot、USD-M Futures、本地历史、风险审查和可选只读账户 Skills。
- 使用隔离 Ed25519 `USER_DATA` Profile 读取账户，不包含状态修改 endpoint。
- 提供内存/SQLite 缓存和 DuckDB/Parquet 历史存储。
- 支持历史 K 线以及 Binance 逐笔数据集（原始 `trades` 与 `aggtrades`），覆盖 Spot 与 USD-M，具备按市场去重、文件级时间裁剪与分桶聚合。
- 支持基于逐笔数据的订单流复盘：大单名义额阈值、扫单档数、按价位成交次数，以及用于交叉验证的 USD-M `metrics` 与 `bookdepth` 快照序列。
- 提供跨平台数据根目录、导入路径约束与有界 HTTPS 导入；连接绑定到已校验的地址。
- 提供 MCP、包消费者和跨交付物校验。

## 下一阶段

- 自动发现 `data.binance.vision` 目录与校验值。
- 增加历史资金费率、持仓量、交易者比例、主动成交量与基差数据集。
- 一致展示请求权重、来源数据年龄与获取时间。
- 增加发布来源证明和制品 attestations。
- 增加可选 WebSocket 市场数据与快照/增量顺序测试。

## 明确独立的未来产品

交易执行应使用另一个 testnet-first 服务，并具备预览、明确确认、交易过滤器校验、幂等、限额和审计日志，不能通过账户 Profile 配置启用。提现能力继续排除在范围外。
